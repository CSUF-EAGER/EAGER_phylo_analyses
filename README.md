## ARG (Ancestral Recombination Graph) Demo!

This lab goes over how to generate an ARG and some of the different analyses you can do with them to learn about a species history.
To demonstrate this we will look at chromosome 9 of the human genome which contains the ABO gene, which is correlated to your blood type.

## Getting Started
### Setting up environment
1. Open a (Nautilus Server)[https://tsc.fullerton.edu/supercomputing/nautilus.html] with the data science stack and medium compute
2. In the terminal of the server run: `conda install conda-forge::git-lfs`
3. Then run: `git lfs install`

### Clone the repo
1. Open a terminal and run the command ```git clone https://github.com/CSUF-EAGER/EAGER_phylo_analyses```
2. Go into the directory `cd EAGER_phylo_analyses`
3. Follow the instructions in ARG_demo.ipynb
